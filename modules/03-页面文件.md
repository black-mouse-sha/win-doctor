# 页面文件：最容易被网上教程坑的地方

这一篇单独拿出来讲，因为**九成人的电脑卡，根源都在这儿**，而且网上给的建议基本是错的。

---

## 先说它到底是什么

你电脑里有两种「存东西的地方」：

```
内存（RAM）   正在用的数据放这儿，快，但断电就没
硬盘         长期存文件，慢，但断电还在
```

**页面文件（pagefile.sys）是两者的中间产物**：硬盘上的一个特殊文件，专门给内存当「备用堆放区」。

它干的事：

```
内存快满了
   ↓
系统挑出「冷数据」（切走的标签页、后台挂着的程序）
   ↓
把这些数据写到 pagefile.sys
   ↓
内存腾出来了，新程序能用
   ↓
你切回那个标签 → 系统从硬盘读回来 → 卡 0.5~2 秒
```

---

## 🔴 最重要的一句话

> **它不会让你的内存变大。**

很多人以为「页面文件 = 虚拟内存 = 白送的内存」，这是错的。

准确的说法：

```
不是：  16 GB 内存 → 变成 35 GB 内存
而是：  16 GB 内存 + 一个堆放区，让系统不至于因为「没地方放」而杀程序
```

打个比方：

```
内存      = 你的书桌（16 平米）
页面文件  = 旁边的货架

桌面放不下了：
  没有货架 → 只能把书扔掉（程序被杀）
  有货架   → 先堆到货架上，要用再搬回来（卡一下）
```

**桌子一点没变大。** 变的只是「东西不会掉地上」。

---

## 那它到底有什么用

用处就一个：**防止程序被系统踢出去。**

你可能会遇到这些症状：

- 开着一堆标签，切回去发现页面白了，要重新加载
- Cursor / VS Code 突然整个窗口消失
- 游戏玩到一半闪退
- 日志里出现 `oom`、`out of memory`、`内存不足`

这些**都是同一个原因**：物理内存满了，又没有地方周转，系统只能杀进程。

**加了页面文件之后：**

```
以前：内存满 → 程序被杀 → 你丢了工作
现在：内存满 → 卡一下   → 东西都还在
```

**从「会死」变成「会顿」。** 这就是全部收益。

## 怎么查自己的配置

### 三个数字

```powershell
$os = Get-CimInstance Win32_OperatingSystem

# 物理内存
"物理内存: {0:N1} GB" -f ($os.TotalVisibleMemorySize/1MB)

# 提交上限（= 物理内存 + 页面文件）
"提交上限: {0:N1} GB" -f ($os.TotalVirtualMemorySize/1MB)
```

**看差额：**

```
提交上限 - 物理内存 = 页面文件给你的缓冲
```

| 物理内存 | 提交上限 | 差额 | 判断 |
|---|---|---|---|
| 16 GB | 17.7 GB | 1.7 GB | ❌ 太小，内存一满就杀程序 |
| 16 GB | 35.7 GB | 19.7 GB | ✅ 正常 |
| 8 GB | 12 GB | 4 GB | ⚠️ 偏小，但 8 GB 机器这样也常见 |

**经验值：差额至少应该是物理内存的一半，最好接近 1 倍。**

### 配置本身

```powershell
(Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management' -Name PagingFiles).PagingFiles
```

输出举例：

```
C:\pagefile.sys 2048 2048
```

格式是 `盘符:\pagefile.sys 初始MB 最大MB`。

**如果初始值 = 最大值，比如 2048 2048 —— 这是手动设的固定值，Windows 自己不会这么配。**

### 实际在用的

```powershell
Get-CimInstance Win32_PageFileUsage
```

这个才准。**配置里写了但这里没有，就是没生效。**

### 有没有僵尸文件

```powershell
cmd /c "dir C:\pagefile.sys /a"
cmd /c "dir D:\pagefile.sys /a"
cmd /c "dir F:\pagefile.sys /a"
```

文件存在、但 `Win32_PageFileUsage` 里没有 → 白占硬盘。

## 怎么改

### 第一步：先决定放哪块盘

**优先级：**

```
① 独立的第二块 SSD     ← 最好，读写不跟系统盘抢
② 系统盘 C:            ← 次好，够用
③ 机械硬盘              ← 别，会慢到怀疑人生
```

**不是「哪个分区空间大就放哪」，要看是不是同一块物理盘。**

查盘符对应哪块物理盘：

```powershell
foreach ($dl in @('C','D','F')) {
  $p = Get-Partition -DriveLetter $dl -ErrorAction SilentlyContinue
  if ($p) {
    $d = Get-Disk -Number $p.DiskNumber
    "$dl : Disk$($d.Number)  $($d.FriendlyName)"
  }
}
```

如果 C 和 D 是 `Disk0`，F 是 `Disk1` —— **放 F**，因为它是独立的一块盘。

### 第二步：怎么算大小

```
16 GB 内存 → 初始 16 GB，最大 32 GB     （放独立盘）
16 GB 内存 → 系统盘留 4~8 GB，剩下的放独立盘
```

**C 盘不用给太大**，4~8 GB 就够，因为：

- 蓝屏转储需要一点空间
- 有些老程序硬编码去 C 盘找页面文件

### 第三步：改配置（管理员权限）

**最可靠的方式是直接写注册表**，因为 WMI 那个接口会静默失败（见 [坑 4](../docs/03-踩过的坑.md)）：

```powershell
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v PagingFiles /t REG_MULTI_SZ /d "C:\pagefile.sys 4096 8192\0F:\pagefile.sys 16384 32768" /f
```

- 多条用 `\0` 分隔
- 结尾 `/f` 表示强制覆盖

**同时确认「自动管理」是关的：**

```powershell
(Get-CimInstance Win32_ComputerSystem).AutomaticManagedPagefile
# 必须是 False
# 如果是 True：
$cs = Get-CimInstance Win32_ComputerSystem
$cs | Set-CimInstance -Property @{ AutomaticManagedPagefile = $false }
```

### 第四步：删掉僵尸文件（关键）

**这一步很多人漏掉，然后重启发现没生效。**

如果目标盘上有个旧的 `pagefile.sys`，而且大小跟新配置对不上，**系统会静默跳过挂载**。

```powershell
# 管理员
takeown /f F:\pagefile.sys /a
icacls F:\pagefile.sys /grant administrators:F
Remove-Item F:\pagefile.sys -Force
```

### 第五步：重启

页面文件只在启动时创建，**必须重启才生效**。

### 第六步：验证

```powershell
# 提交上限应该变大了
(Get-CimInstance Win32_OperatingSystem).TotalVirtualMemorySize / 1MB

# 活动页面文件应该列出每一块盘
Get-CimInstance Win32_PageFileUsage
```

---

## ⚠️ 如果重启后没生效

按这个顺序排查：

**① 看配置还在不在**

```powershell
(Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management' -Name PagingFiles).PagingFiles
```

**② 看目标盘上的旧文件删没删**

```powershell
cmd /c "dir F:\pagefile.sys /a"
```

还在 → 删掉再重启一次。

**③ 看自动管理是不是被打开了**

```powershell
(Get-CimInstance Win32_ComputerSystem).AutomaticManagedPagefile
```

如果是 `True`，你的手动配置会被忽略。

**④ 看那块盘是不是动态磁盘 / 有特殊属性**

```powershell
Get-Partition -DriveLetter F
Get-Disk -Number (Get-Partition -DriveLetter F).DiskNumber
```

## 常见误区表

| 你以为 | 实际 |
|---|---|
| 「页面文件 = 虚拟内存 = 白送的内存」 | 不增加内存，只是防止崩溃 |
| 「设大点电脑会变快」 | 不会，只会变稳 |
| 「放哪块盘都行」 | 机械盘会拖慢整个系统 |
| 「C 盘空间不够，全挪到 D 盘」 | C 盘留 4~8 GB，蓝屏转储要用 |
| 「设完立刻生效」 | 必须重启 |
| 「配置文件里有就是生效了」 | 要看 `Win32_PageFileUsage` |
| 「不用页面文件，设成 0 就行」 | 现代 Windows 不建议，会限制很多功能 |
| 「SSD 有寿命，别放页面文件」 | 现代 SSD 的写入寿命远超你的想象，值得 |
