# 开机自启：查三个地方，不是两个

大部分人只知道前两个，第三个藏着一半的答案。

---

## 三个地方

```
① 注册表 HKCU Run         当前用户的程序
② 注册表 HKLM Run         所有用户的程序
③ 启动文件夹              丢个快捷方式进去就自启
④ 任务计划程序             登录/开机触发 ← 最容易漏
```

---

## 怎么查

### ① + ② 注册表

```powershell
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' | Select-Object * -ExcludeProperty PS*
Get-ItemProperty 'HKLM:\Software\Microsoft\Windows\CurrentVersion\Run' | Select-Object * -ExcludeProperty PS*
```

输出会长这样：

```
OneDrive        "C:\Program Files\Microsoft OneDrive\OneDrive.exe" /background
Steam           "F:\steam\steam.exe" -silent
Docker Desktop  C:\Users\xxx\AppData\Local\Programs\DockerDesktop\Docker Desktop.exe
```

### ③ 启动文件夹

```powershell
Get-ChildItem "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup"
Get-ChildItem "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\Startup"
```

这里的都是 `.lnk` 快捷方式。

### ④ 任务计划

```powershell
Get-ScheduledTask | Where-Object {
  $_.State -ne 'Disabled' -and
  ($_.Triggers | Where-Object { $_.CimClass.CimClassName -match 'Logon|Boot' })
} | ForEach-Object {
  $exe = ($_.Actions | Select-Object -First 1).Execute
  "{0,-50} {1}" -f $_.TaskName, $exe
}
```

**注意分辨**：输出里大多数是 Windows 自己的系统维护任务，别动。

```powershell
# 只看第三方的（路径不在 Windows 目录下）
Get-ScheduledTask | Where-Object {
  $_.State -ne 'Disabled' -and
  ($_.Triggers | Where-Object { $_.CimClass.CimClassName -match 'Logon|Boot' })
} | Where-Object {
  $exe = ($_.Actions | Select-Object -First 1).Execute
  $exe -and $exe -notmatch '\\Windows\\|\\system32\\' -and $exe -notmatch '^%'
} | Select-Object TaskName
```

## 怎么判断该关哪个

### 三档分类

**保留**

```
杀毒软件           火绒、Defender、360
硬件驱动           声卡、显卡、网卡相关
安全中心           SecurityHealth
文件搜索           Everything
输入法
```

**看你用不用**

```
终端               Warp、Windows Terminal
快捷启动           Quicker、uTools（两个功能重复，留一个）
网盘               OneDrive、阿里云盘、百度网盘
聊天               微信、QQ、飞书、钉钉
笔记               OneNote、Obsidian
```

**建议关掉**

```
游戏平台           Steam、Epic、战网
动态壁纸           Wallpaper Engine（吃 GPU + 内存）
本地大模型         Ollama（不用时纯占内存）
更新器             Adobe、QQ浏览器、各类 Updater
早就卸载的残留     名字眼熟但找不到主程序
```

## 怎么关

### 备份（必做）

```powershell
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
$bk = "$env:USERPROFILE\Documents\autostart-backup-$stamp"
New-Item -ItemType Directory -Path $bk -Force | Out-Null

reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" "$bk\HKCU-Run.reg" /y
reg export "HKLM\Software\Microsoft\Windows\CurrentVersion\Run" "$bk\HKLM-Run.reg" /y
Copy-Item "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\*" "$bk\" -Force
```

**还原的时候双击 `.reg` 文件就行。**

### 关注册表项

```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name '项名' -Force
```

### 关启动文件夹

```powershell
# 别直接删，先移到备份目录
Move-Item "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\xxx.lnk" $bk
```

### 关任务计划

```powershell
Disable-ScheduledTask -TaskName '任务名' -TaskPath '路径'
```

**用「禁用」而不是「删除」**，随时能开回来。

## 两个坑

### 坑 1：删了又回来

Edge 这类软件会在启动时检查自己的设置，觉得「我该开机启动」，就把注册表项写回去。

**解决办法：改软件自己的设置，不要只删注册表。**

```
Edge: 设置 → 系统和性能 → 启动时 → 关掉「系统启动时自动启动 Microsoft Edge」
```

### 坑 2：只删了注册表，任务计划里还有一个

比如 OneDrive：

```
注册表 Run        ✅ 删了
启动文件夹        ✅ 没有
任务计划           ❌ 还有两个 "OneDrive Startup Task-S-1-5-..."
```

**那它照样会起来。** 三个地方都要查。

## 效果能有多大

实测一台机器：

```
清理前   23 项注册表 + 3 个启动文件夹 + 10 个任务计划
清理后    7 项 + 0 + 0

开机后内存占用少了约 1.9 GB
```

算下来大概是这些：

```
Steam             ~250 MB
Docker Desktop    ~400 MB
Ollama            ~200 MB
OneDrive          ~120 MB
阿里云盘           ~100 MB
飞书              ~200 MB
Edge 自启          ~150 MB
其他杂项           ~250 MB
```
