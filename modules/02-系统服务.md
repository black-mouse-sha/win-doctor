# 系统服务：改「手动」就够了，别急着禁用

很多人一看到几十个服务在跑就想全关，结果声卡没了、网连不上、打印机用不了。

这一篇讲清楚：**哪些能动，哪些一动就出事，以及为什么「手动」比「禁用」安全。**

---

## 先搞懂三种状态

```
自动 (Auto)      开机就起，从早到晚跑
手动 (Manual)    开机不起，要用的时候起
禁用 (Disabled)  永远不起
```

**关键认知：改「手动」不等于关掉。**

它是把服务从「全天值班」改成「随叫随到」。软件要用的服务，大多数情况它自己会拉起来（也有例外，见下面）。

---

## ⚠️ 一个必须知道的例外

> **Windows 服务不会因为某个程序去连接它而自动启动。**

这条最反直觉，很多人踩过：

```
把 MySQL80 改成「手动」
→ 打开 Navicat 连接
→ 连接失败
```

因为 Navicat 只是去连 3306 端口，**不会触发服务启动**。只有「服务依赖服务」的关系才会自动拉起。

**所以：**

| 类型 | 例子 | 建议 |
|---|---|---|
| 软件一开就必需 | MySQL、SQL Server、许可证服务 | **留自动** |
| 只在特定操作时需要 | VMware NAT/DHCP、USB 直通 | 改手动（用软件时会拉起来） |
| 后台更新器 | QQ浏览器、Adobe、Edge | 改手动 |
| 纯装饰 | 罗技灯效、壁纸引擎 | 改手动 |
| 已经死了的软件 | Flash | 禁用 |

## 怎么查

```powershell
# 所有自动启动的服务
Get-CimInstance Win32_Service | Where-Object { $_.StartMode -eq 'Auto' } |
  Select-Object Name, State, DisplayName | Format-Table -AutoSize

# 只看第三方的（路径不在 Windows 目录）
Get-CimInstance Win32_Service | Where-Object {
  $_.StartMode -eq 'Auto' -and
  $_.PathName -notmatch '\\Windows\\|\\system32\\' -and
  $_.PathName -notmatch '^%'
} | Select-Object Name, DisplayName, PathName | Format-Table -AutoSize -Wrap
```

## 改造清单（按风险分）

### 🟢 可以改「手动」—— 不影响任何软件使用

| 服务 | 干什么 |
|---|---|
| `VMAuthdService` | VMware 授权 |
| `VMnetDHCP` | VMware 虚拟网 DHCP |
| `VMUSBArbService` | VMware USB 直通 |
| `VMware NAT Service` | VMware NAT 网络 |
| `QQBrowserUpdateService` | QQ 浏览器更新 |
| `TxQBService` | QQ 浏览器服务 |
| `AdobeUpdateService` | Adobe 更新 |
| `logi_lamparray_service` | 罗技 RGB 灯效 |

**为什么安全**：VMware 打开时会把需要的拉起来；更新器本来就不该常驻；灯效不调就不需要。

### 🔴 可以「禁用」—— 纯垃圾

| 服务 | 是什么 |
|---|---|
| `Flash Helper Service` | Flash 辅助 —— **Flash 2020 年底已停止支持** |
| `FlashCenterSvc` | 某些国产 Flash 套件带的 |

### 🟡 看情况 —— 要自己判断

| 服务 | 说明 |
|---|---|
| `MySQL80` / `SQL Server` | **天天用就留自动**，偶尔用可以手动 + `net start` |
| `WSLService` | 用 WSL 就留 |
| `Docker Desktop` 相关 | 开发时留，平时可以改手动 |
| `ClickToRunSvc` | Office 点击运行，建议留自动 |

### 🚫 绝对别动

```
HipsDaemon / WinDefend / 360 服务    杀毒软件
AudioSrv / AudioEndpointBuilder      声音
NVDisplay.ContainerLocalSystem       显卡
RtkAudioUniversalService             声卡驱动
BFE                                  防火墙
CoreMessagingRegistrar               系统消息
DcomLaunch / RpcSs                   系统核心
```

### 🚫 公司电脑的更要小心

如果这台机器上有这些东西：

```
零信任 VPN、SDP 客户端、单点登录、数字证书服务
```

**一个都别动。** 它们经常带设备合规检测：

- 关了 → 可能判定「设备不合规」
- 轻则重新认证，重则 IT 找上门
- 有些卸载要重新申请授权

省几十 MB 内存，换来明天上不了班，不值。

## 怎么改

### 改启动方式（管理员）

```powershell
Set-Service -Name "服务名" -StartupType Manual     # 或 Automatic / Disabled
```

### 停掉当前正在跑的

**改启动方式不会停掉正在运行的服务**，得单独停：

```powershell
Stop-Service -Name "服务名" -Force
```

### 完整操作示例

```powershell
# 以 VMware 为例
$svcs = @('VMAuthdService','VMnetDHCP','VMUSBArbService','VMware NAT Service')

foreach ($s in $svcs) {
    Set-Service -Name $s -StartupType Manual
    Stop-Service -Name $s -Force -ErrorAction SilentlyContinue
    $now = Get-Service -Name $s
    "$s : $($now.Status) / $((Get-CimInstance Win32_Service -Filter "Name='$s'").StartMode)"
}
```

## 效果实测

一台机器上改了 11 个服务：

```
9 个改手动 + 2 个禁用 + 11 个停止
可用内存  5.19 GB  →  6.13 GB     释放 0.94 GB
```

不算多，但免费，而且是一次性的。

## 出问题了怎么救

### 服务起不来了

```powershell
# 先看状态
Get-Service -Name "服务名"

# 手动启动看报什么错
Start-Service -Name "服务名"

# 改回自动
Set-Service -Name "服务名" -StartupType Automatic
Start-Service -Name "服务名"
```

### 不知道改了哪些

```powershell
# 列出所有「手动」的服务，跟你记得的对一下
Get-CimInstance Win32_Service | Where-Object { $_.StartMode -eq 'Manual' } |
  Select-Object Name, DisplayName | Format-Table -AutoSize
```

### 图形界面改

```
Win + R → services.msc → 回车
找到服务 → 右键 → 属性 → 启动类型
```

微信/QQ/Docekr 这类软件重装时经常把自己改成自动，定期回来看一眼。
