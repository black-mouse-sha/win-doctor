# 软件清理：装了但一年没打开的

这一篇最短，因为道理最简单：**装了一堆用不上的东西，它们要么在后台跑，要么在硬盘躺着。**

---

## 先看看自己装了多少

```powershell
Get-ItemProperty @(
  'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*'
) -ErrorAction SilentlyContinue |
  Where-Object { $_.DisplayName -and -not $_.SystemComponent } |
  Select-Object DisplayName, DisplayVersion, Publisher |
  Sort-Object DisplayName -Unique
```

一般会有 60~100 个。**正常人会用的不超过 20 个。**

## 四类该清的

### 一类：已经死了的软件

| 名字 | 为什么该删 |
|---|---|
| `Adobe Flash Player` | **2020 年 12 月 31 日停止支持**，现在纯属漏洞库 |
| `FlashCenter` / `Flash Helper` | 国产 Flash 套件带的，配套垃圾 |
| 各种「XX 加速器」残留 | 加速器厂商倒闭了，程序还在 |

Flash 特别典型：一台机器上同时装了 ActiveX 和 PPAPI 两个版本，加起来占几百兆，还常驻两个服务。

```powershell
# 先看有没有
Get-ItemProperty HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* |
  Where-Object { $_.DisplayName -match 'Flash' } |
  Select-Object DisplayName, UninstallString
```

### 二类：功能重复的

```
浏览器     Edge + Chrome + QQ浏览器 + 360 + ...    留 1~2 个
下载器     IDM + 迅雷 + Motrix + AB Download       留 1 个
快捷启动   Quicker + uTools + 各种 Dock           留 1 个
压缩软件   WinRAR + 7-Zip + Bandizip + 好压        留 1 个
输入法     搜狗 + 微软 + QQ                        留 1 个
```

**每个重复的软件都是一个后台服务 + 一个更新器 + 一个开机自启项。**

### 三类：装完就没打开过的

按安装时间排序，看看有哪些是一年前装的但从来没点过：

```powershell
Get-ItemProperty @(
  'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*'
) -ErrorAction SilentlyContinue |
  Where-Object { $_.DisplayName -and $_.InstallDate } |
  Select-Object DisplayName, InstallDate, @{n='位置';e={$_.InstallLocation}} |
  Sort-Object InstallDate
```

### 四类：占用大但用得少的

```powershell
# 按目录大小排（这个跑得慢，耐心等）
$paths = @('C:\Program Files','C:\Program Files (x86)',"$env:LOCALAPPDATA\Programs",'D:\Program Files','D:\new download')
foreach ($p in $paths) {
  if (Test-Path $p) {
    Get-ChildItem $p -Directory -ErrorAction SilentlyContinue | ForEach-Object {
      $sz = (Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue |
             Measure-Object Length -Sum).Sum
      if ($sz -gt 500MB) {
        [PSCustomObject]@{ GB = [math]::Round($sz/1GB,2); Path = $_.FullName }
      }
    }
  }
} | Sort-Object GB -Descending | Select-Object -First 20
```

## 怎么卸

### 图形界面

```
设置 → 应用 → 已安装的应用 → 找到 → 卸载
```

**最安全，卸载程序会自己清理注册表和服务。**

### 命令行

```powershell
# 看卸载命令
$u = Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*' |
  Where-Object { $_.DisplayName -match '软件名' }
$u.UninstallString
```

然后手动执行那个命令。

### ⚠️ 别直接删目录

删了文件夹，注册表条目、服务、开机自启项全都留着。

**结果：开机报错找不到文件，或者服务启动失败。**

## 常见问题

### 卸不干净怎么办

用官方卸载程序跑一遍，然后检查：

```powershell
# 残留的服务
Get-Service | Where-Object { $_.DisplayName -match '软件名' }

# 残留的自启项
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' | Select-Object * -ExcludeProperty PS*
```

---

### 这个能删吗

不确定的时候，按这个顺序判断：

```
1. 是驱动吗？           → 别删
2. 是运行库吗？         → 别删（.NET、VC++、DirectX）
3. 是杀毒吗？           → 别删
4. 是公司软件吗？       → 先问 IT
5. 其他                 → 先查一下它是干嘛的，再决定
```

**特别提醒：`Microsoft Visual C++ Redistributable` 那一堆看着像重复，其实是不同版本，很多程序依赖其中一个。别删。**

## 一个真实例子

一台机器上装了 94 个软件，其中：

```
Adobe Flash Player 34 x2      ← 死软件
FlashCenter                   ← 配套垃圾
QQ浏览器 + Chrome + Edge + Tabbit   ← 四个浏览器
Copilot                       ← 中国大陆打不开，占 924 MB
```

清掉这几个，大概能省 2~3 GB 硬盘，加上几个后台服务。
