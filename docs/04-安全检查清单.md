# 安全检查清单

动手之前过一遍，能避免八成的事故。

---

## 动手前

- [ ] **确认这台电脑是你自己的**
      公司/学校发的机器，那些安全客户端（零信任 VPN、SDP、单点登录）一个都不能动

- [ ] **确认装了什么杀毒软件**
      火绒、360、Defender 的服务全部保留

- [ ] **重要文件已经备份**
      不一定要全盘备份，但正在做的项目、照片、文档要有一份在别处

- [ ] **知道怎么还原**
      注册表备份在哪、服务原值是什么，心里有数

- [ ] **手机能上网**
      万一改完网络出问题，还能查资料

---

## 动手时

### 通用规矩

- [ ] **一次只改一项**
      改五项然后出问题，你不知道是哪项导致的

- [ ] **先备份再改**
      注册表导出 `.reg`，文件复制到备份目录

- [ ] **优先「手动」，别急着「禁用」**
      禁用 = 彻底关死，出问题不好救

- [ ] **改完立刻验证**
      把改之前和改之后的值都看一眼

### 按风险分级

| 操作 | 风险 | 能不能救 |
|---|---|---|
| 删注册表 Run 项 | 低 | ✅ 双击备份 .reg |
| 移走启动文件夹快捷方式 | 低 | ✅ 移回来 |
| 禁用任务计划 | 低 | ✅ 启用回来 |
| 服务改「手动」 | 中 | ✅ 改回自动 |
| 服务改「禁用」 | 中高 | ✅ 改回自动，但要重启 |
| 改页面文件 | 中 | ✅ 改回原值重启 |
| 卸载软件 | 中 | ⚠️ 要重装 |
| 删系统目录文件 | 高 | ❌ 可能重装系统 |

## 绝对不做的事

### ❌ 动杀毒软件

```
HipsDaemon (火绒)
WinDefend (Windows Defender)
360 相关服务
```

关掉之后不只是没防护，有些软件还会检测「杀软被关」然后拒绝运行。

### ❌ 动公司安全客户端

```
零信任 VPN
SDP 客户端
单点登录
数字证书服务
```

这些经常带**设备合规检测**。关了可能：

- 被判定「设备不合规」
- 强制重新认证
- 触发 IT 告警

**省几十 MB，换来明天上不了班。**

### ❌ 动系统核心服务

```
DcomLaunch / RpcSs / lsass / services
```

这些一停系统直接蓝屏或者重启。

### ❌ 动硬件驱动

```
显卡驱动、声卡驱动、网卡驱动、芯片组
```

### ❌ 用第三方「优化大师」一键优化

这类软件干的事通常是：

- 关掉它认为「没用」的服务（往往是关键服务）
- 清理它认为「垃圾」的文件（有时候是系统文件）
- 改注册表（留下隐患）

**手动一项一项来，比一键优化慢，但你知道自己在干什么。**

## 改页面文件的额外注意

- [ ] **确认目标盘是 SSD**
      机械盘放页面文件会拖慢整个系统

- [ ] **确认目标盘是独立物理盘**
      C 和 D 在同一个 Disk0 上，效果比放在 Disk1 差

- [ ] **C 盘要留 4~8 GB**
      蓝屏转储需要

- [ ] **删掉旧文件再重启**
      目标盘上有个大小不匹配的旧 `pagefile.sys`，系统会静默跳过

- [ ] **确认自动管理是关的**
      否则你的手动配置会被忽略

---

## 重启前的最后检查

```powershell
# 1. 配置写对了吗
(Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management' -Name PagingFiles).PagingFiles

# 2. 自动管理关了吗
(Get-CimInstance Win32_ComputerSystem).AutomaticManagedPagefile

# 3. 目标盘空间够吗
Get-CimInstance Win32_LogicalDisk -Filter "DeviceID='F:'" | Select-Object DeviceID, FreeSpace

# 4. 有没有僵尸文件
cmd /c "dir F:\pagefile.sys /a"
```

四条都对了再重启。

---

## 重启后验证

```powershell
# 提交上限应该变大了
(Get-CimInstance Win32_OperatingSystem).TotalVirtualMemorySize / 1MB

# 活动页面文件应该列出每一块盘
Get-CimInstance Win32_PageFileUsage
```

**如果没变**：

1. 检查旧文件删了没
2. 检查自动管理关没关
3. 再重启一次

## 出事了怎么办

### 症状：某个软件打不开了

```powershell
# 大概率是它的服务被改了
Get-Service -Name "软件名相关"
Set-Service -Name "服务名" -StartupType Automatic
Start-Service -Name "服务名"
```

### 症状：没声音了

```powershell
Set-Service -Name AudioSrv -StartupType Automatic
Set-Service -Name AudioEndpointBuilder -StartupType Automatic
Start-Service -Name AudioEndpointBuilder
Start-Service -Name AudioSrv
```

### 症状：连不上网

```powershell
# 先看代理软件
Get-Process | Where-Object { $_.ProcessName -match 'clash|v2ray|xray|singbox' }
# 再看网络服务
Get-Service -Name Dnscache, Dhcp, NlaSvc | Select-Object Name, Status
```

### 症状：开机一直转圈，进不去系统

```
开机时狂按 F8 或者 Shift + F8
→ 进入高级启动
→ 安全模式
→ 按备份还原
```

配置文件在：

```
HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management
键名：PagingFiles
```

---

## 一句话总结

> **能救的：注册表、文件位置、服务状态、页面文件配置**
> **不能救的：删掉的文件、卸载的软件、系统核心被破坏**
>
> **所以：只动能救的，别碰不能救的。**
