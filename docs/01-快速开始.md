# 快速开始

三条路，挑一条走。

---

## 路线 A：丢给 AI（最省事）

1. 复制这段，发给任意支持联网的 AI

```
读一下这个仓库：
https://github.com/black-mouse-sha/win-doctor

然后按 AGENT-GUIDE.md 的流程，一步一步带我查我的 Windows 电脑。
一次只做一件事，动手前先说清楚要改什么、有什么风险，等我说可以了再动。
改之前先备份，改完把改前改后的值都打出来。
```

2. AI 会先问你三个问题

```
电脑是公司发的还是自己的？
装没装杀毒软件？
主要拿来干嘛？
```

3. 然后一项一项往下走

```
体检 → 找瓶颈 → 列清单 → 一项一项改 → 重启验证
```

**适合**：不想记命令、怕改坏、想要个懂行的在旁边看着。

---

## 路线 B：自己跑（最直接）

### 第一步：体检

```powershell
# 下载并运行（记得换成你的仓库地址）
powershell -NoProfile -ExecutionPolicy Bypass -File .\check.ps1
```

或者直接克隆：

```powershell
git clone https://github.com/black-mouse-sha/win-doctor.git
cd win-doctor
powershell -NoProfile -ExecutionPolicy Bypass -File .\check.ps1
```

**这个是只读的，不会改任何东西。** 放心跑。

### 第二步：看输出

体检报告会告诉你：

```
② 内存
  物理内存   15.69 GB
  可用        1.89 GB  (已用 88%)

③ 页面文件
  提交上限   19.69 GB
  差额        4 GB
  ⚠ 诊断：页面文件太小
```

红色/黄色标出来的，就是问题。

### 第三步：按提示去对应的模块

```
页面文件有问题  →  modules/03-页面文件.md
开机自启太多    →  modules/01-开机自启.md
服务太多空转    →  modules/02-系统服务.md
```

---

## 路线 C：只看文档（最谨慎）

直接翻 `modules/` 和 `docs/`，挑你关心的看。

每一篇都是独立的，可以只看一节。

---

## 推荐顺序

如果你不知道从哪下手，按这个顺序：

```
1. 跑 check.ps1  →  知道问题在哪
2. 先弄页面文件  →  影响最大，改完立刻见效
3. 再清开机自启  →  减少后台常驻
4. 最后清服务    →  收益最小，但顺手
5. 重启验证
```

---

## 大概要花多久

```
体检               1 分钟
看报告             3 分钟
页面文件           5 分钟（改完要重启）
开机自启           10~20 分钟（取决于你要不要一个个确认）
系统服务           5 分钟
重启验证           2 分钟
────────────────────────
合计               半小时左右
```

---

## 中途出问题怎么办

### 别慌，全部可逆

```
注册表   →  双击备份的 .reg 文件
文件夹   →  从备份目录移回去
服务     →  Set-Service -Name "名字" -StartupType Automatic
页面文件 →  改回原来的值，重启
```

### 备份在哪

```powershell
# 找最近的备份
Get-ChildItem "$env:USERPROFILE\Documents\autostart-backup-*" |
  Sort-Object Name -Descending | Select-Object -First 1
```

### 实在搞不定

开 Issue，贴 `check.ps1` 的输出 + 你改了什么。
