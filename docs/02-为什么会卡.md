# 为什么会卡

「电脑卡」是个很笼统的说法。实际上有五种完全不同的卡，对应的解决方法也完全不同。

先搞清楚你是哪一种。

---

## 先把这台机器想象成一家餐厅

| 电脑里的东西 | 餐厅里对应的角色 | 干嘛的 |
|---|---|---|
| CPU | 厨子 | 切菜炒菜算账，什么都干 |
| 内存 RAM | 操作台 | 正在做的菜必须放这 |
| 硬盘 SSD | 仓库 | 存原料，慢但持久 |
| 显卡 GPU | 专门做雕花的师傅 | 画面、AI 计算 |
| 显存 VRAM | 雕花师傅自己的工作台 | 只有他能用 |
| 页面文件 | 临时堆货区 | 操作台不够时把东西先挪走 |

---

## 五种卡，你是哪一种

### ① 开几个程序就卡死，程序还会自己消失

**症状**

```
开着浏览器 + 微信 + 编辑器
再开一个软件 → 卡住几秒
然后某个程序直接没了，窗口消失
```

**原因**：内存不够 + 页面文件太小。

系统内存满了，没地方周转，只能**杀掉优先级低的进程**。这就是为什么会「自己消失」。

日志里通常能看到：

```
renderer process gone (reason: oom, code: -536870904)
```

`oom` = out of memory。

**怎么确认**

```powershell
$os = Get-CimInstance Win32_OperatingSystem
"物理内存: {0:N1} GB" -f ($os.TotalVisibleMemorySize/1MB)
"提交上限: {0:N1} GB" -f ($os.TotalVirtualMemorySize/1MB)
```

差额小于物理内存的一半 → 就是这个问题。

**怎么解决** → [modules/03-页面文件.md](../modules/03-页面文件.md)

---

### ② 整个系统一顿一顿，硬盘灯一直闪

**症状**

```
不是某个程序卡，是整个电脑卡
鼠标移动都一顿一顿
任务管理器里内存 95%+
硬盘读写一直满
```

**原因**：内存不够，系统在**疯狂换页**。

把内存数据疯狂写到硬盘、再读回来，反复循环。硬盘被榨干，整个系统跟着卡。

专业说法叫「内存抖动」（memory thrashing）。

**这个比 ① 更严重**，因为加页面文件只能缓解，根治要加内存条。

**怎么确认**

任务管理器 → 性能 → 内存，看「已提交」是不是贴着上限。

**怎么解决**

- 短期：加大页面文件（[modules/03](../modules/03-页面文件.md)）
- 根治：加内存条

---

### ③ 跑 AI 模型慢，或者报 out of memory

**症状**

```
ollama run 某个模型
→ 很慢，一个字一个字蹦
→ 或者直接报错
```

**原因**：显存不够，或者根本没在用显卡。

**关键：AI 吃的是显存，不是内存，也不是缓存。**

**怎么确认**

跑模型的时候打开任务管理器 → 性能 → GPU：

```
GPU 60~90%   → 正常在用显卡
GPU 0~5%     → 确诊，在用 CPU 硬算（慢 20 倍）
```

**显存能跑多大的模型**

| 模型 | Q4 量化大小 | 8 GB 显存 |
|---|---|---|
| 7B | ~4.4 GB | ✅ 舒服 |
| 8B | ~5.0 GB | ✅ 舒服 |
| 14B | ~8.9 GB | ⚠️ 差 1 GB，要卸载几层 |
| 32B | ~19 GB | ❌ 跑不动 |

**怎么解决**

- 小了：关掉其他占显存的程序
- 大了：换更小的模型
- 慢：确认有没有用上 GPU

---

### ④ 玩游戏掉帧

**症状**

```
玩一会儿开始卡
帧数从 60 掉到 20
或者画面突然模糊（贴图变糊）
```

**原因**：显存爆了，或者显卡性能不够。

**「爆显存」的表现**

```
贴图突然变模糊
走两步卡一下
帧数断崖式下跌
```

不会报错，就是画面变差。

**怎么解决**

降画质、降分辨率。8 GB 显存适合 1080p 高画质，2K 要降设置，4K 别想。

---

### ⑤ 开机特别慢，开机后要等好久才能用

**症状**

```
按电源 → 转圈很久 → 桌面出来了
但鼠标一直在转，点什么都没反应
要等一两分钟才能正常用
```

**原因**：开机自启太多。

二十几个程序同时启动，抢 CPU 抢硬盘抢内存。

**怎么确认** → [modules/01-开机自启.md](../modules/01-开机自启.md)

## 一张对照表

| 症状 | 瓶颈 | 免费方案 | 花钱方案 |
|---|---|---|---|
| 程序自己消失 | 内存 + 页面文件 | 加大页面文件 | 加内存条 |
| 整个系统一顿一顿 | 内存 | 加大页面文件 + 少开程序 | 加内存条 |
| AI 慢或报错 | 显存 | 换小模型 | 换显卡（笔记本不行） |
| 游戏掉帧 | 显存 | 降画质 | 换显卡 |
| 开机慢 | 自启 | 清自启 | — |

---

## 几个反直觉的事实

**① 加页面文件不会让电脑变快**

只会让它「不崩」。原来卡的地方还是卡，只是不会再有程序消失了。

**② 加内存条对 AI 没有帮助**

AI 模型装在显存里，内存再大也进不去。

**③ 清理「垃圾」对速度影响很小**

各种「清理大师」清的那些缓存，实际对速度影响不到 1%。真正让电脑卡的是内存不够和后台程序太多。

**④ CPU 很少是瓶颈**

现代 CPU 对日常使用来说基本过剩。除非你在剪 4K 视频、跑编译、或者做科学计算，否则 CPU 不是你的问题。

**⑤ 硬盘慢≠电脑卡**

这是机械硬盘时代的老观念。你现在是 NVMe SSD，硬盘基本不会成为瓶颈（除非空间快满了）。
